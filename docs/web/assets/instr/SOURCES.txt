Where the sampled instruments came from
=======================================

Trumpet, Flute, Saxophone
  University of Iowa MIS. See LICENSE-IOWA-MIS.txt for the terms and what was
  done to them.

Grand Piano, Upright Piano, Vibraphone, Glockenspiel, Harp, Organ
  Versilian Community Sample Library (VCSL), CC0. See LICENSE-VCSL.txt.
  https://github.com/sgossner/VCSL

Grand Piano, exactly
--------------------
Chordophones/Zithers/Grand Piano, Steinway B/Sus/JHPiano_Sus_Close_C*_vl3_rr1.wav
Sustain pedal down, close mic, velocity layer 3, round robin 1.

piano_c1 .. piano_c7 are C1 through C7 from that set, one every 12 semitones.
Roots are the nominal MIDI numbers 24, 36, 48, 60, 72, 84, 96.

piano_c1 is 18 seconds, not 9. A low C rings for ages and 9 seconds cut it
off well before it died. Use -t 18 and afade st=17.5 for that one.

Processing, if these ever need regenerating:

  ffmpeg -i JHPiano_Sus_Close_C4_vl3_rr1.wav -ac 1 -ar 32000 mono.wav
  ffmpeg -i mono.wav -t 9 -af "afade=t=out:st=8.5:d=0.5" -codec:a libmp3lame -b:a 96k piano_c4.mp3

The downmix has to be its own step. Doing it in the same command as the filters
makes ffmpeg apply a different normalisation and the result comes out louder.

That recipe reproduces the original piano_c4.mp3 at 0.99996 sample correlation
and the same byte count, which is how the settings above were recovered.

It used to be only C2, C4 and C6, 24 semitones apart. Anything above C5 reached
for the C6 sample at half speed, which sounded dull and rang for 17 seconds.

Upright Piano, exactly
----------------------
Chordophones/Zithers/Upright Piano, Yamaha/Sustains/Upright1_Sus_C*_vl2_rr1.wav

Careful: this set numbers its octaves one lower than the Steinway set does.
VCSL C3 is fabu's upright_c4. So upright_c2 came from the file called C1.

  ffmpeg -i src.wav -ac 1 -ar 32000 mono.wav
  ffmpeg -i mono.wav -t 7 -af "afade=t=out:st=6.5:d=0.5" -codec:a libmp3lame -b:a 96k out.mp3

That reproduces upright_c4 at 0.99998 correlation and the same byte count.

upright_as0 is the file VCSL calls C0. It is not C0. Measured across six
harmonics it is 29.44 Hz, which is A#0, midi 22.18, and that measured value is
its root. Do not trust that filename.

Organ, exactly
--------------
Aerophones/Edge-blown Aerophones/Pipe Organ/Loud/Rode_Man3Open_C*.wav
Note the Quiet folder next to it numbers its octaves one higher. Loud matches
fabu's numbering, Quiet does not.

  ffmpeg -ss 1.0 -t 2.6 -i src.wav -ac 1 -ar 44100 \
    -af "afade=t=in:st=0:d=0.1,afade=t=out:st=2.2:d=0.4" -codec:a libmp3lame -b:a 96k out.mp3

Organ roots are measured, not assumed, same as the Iowa instruments. The source
C4 and C5 measure 260.95 Hz and 525.00 Hz, matching fabu's existing samples to
three decimals, which is how this source was confirmed. organ_c6 is 1050.00 Hz,
so its root is 84.058.

Guitars and bass
----------------
All three are CC0, from FreePats (https://freepats.zenvoid.org). VCSL has no
guitars or bass at all, which is why these come from somewhere else.

Bass          FingerBassYR, samples/finger/*.wav
              https://github.com/freepats/electric-bass-YR
              Only covers E1 to D#2. Anything above that is stretched up.
Acoustic      Spanish Classical Guitar, nylon strung
              freepats.zenvoid.org/Guitar/SpanishClassicalGuitar
Electric      EGuitarFSBS clean, bridge pickup, small set
              https://github.com/freepats/electric-guitar-FSBS-clean
              Clean on purpose. The dirt comes from the Amp effect so it can be
              dialled, and because the distorted set is a 300 MB download.

Every root was measured off the file, not read off its name. Same pipeline as
the rest: mono, 32 kHz, trimmed, short fade, mp3 96k.
