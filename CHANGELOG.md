# Changelog

## 1.2.5
- Works on phones and iPads now. It really didn't before.
- Piano roll: octave buttons, the keyboard lives inside it, and recording over a pattern adds to that pattern instead of making a new track.
- Automation lanes under each track. Click to add a point, drag to move it.
- Loop gallery: publish your loops, browse other people's, follow them.
- The loop button no longer looks like undo.
- Keyboard letters match your actual keyboard. QWERTY and AZERTY were wrong before.
- Saving asks for a name instead of opening the file manager.
- Opens filling the screen the first time.
- Closing the app actually closes it.
- The greeting follows the clock.
- You can listen to loops before taking them.
- Kicks stick now. They used to key on the display name.
- Humanize, and automation curves that ease instead of running straight.
- Chord suggestions are gone.
- No more dead File/Edit menu bar on Windows and Linux.

## 1.2.4
- Hold shift and drag an effect across the timeline to put it on every pattern you pass.
- Patterns with effects on them look like it now, and say what's on them.
- Exports can't clip any more.
- A loop for every instrument, plus a jazz set built to stack.
- Dragging feels like dragging. The card follows your cursor.
- Redone export window, tells you how big each format will be.
- MIDI exports get useful track names instead of "Instrument 2".

## 1.2.3
- Everyone in a room needs the same version. It tells you which one now instead of quietly breaking.
- Trumpet, flute, saxophone and a real organ. Actual recordings.
- The old synth "Keys" is gone. Projects using it move to Grand Piano on their own.
- Export MIDI.
- Time signature moved to the bar counter. Click it to change it.
- Settings is split into song and app, and opens from the home screen.
- Rooms are safer. The server refuses messages from people who never joined.
- Big songs and long files stopped breaking.
- Exports could come out silent if you exported straight after opening. Fixed.
- Opening a project from a newer version warns you first.

## 1.2.2
- Windows: grab this one from the website. In app updating was broken and the fix is in here, so it can't rescue the update into it. Sorry.
- Drop a MIDI file on the timeline. It becomes real editable patterns, one lane per instrument.
- Sustain pedal. Shift while the keyboard is open, the Sustain button, or a real pedal.
- Time signatures. 3/4, 6/8 and the rest.
- New projects start empty.
- Windows remember their size and place.
- Big songs stopped breaking. It was asking for a canvas bigger than the browser allows.
- Jam rooms hold together while the server wakes up, and put you back if your wifi drops.
- Real error messages instead of guessing whether it's you or the app.
- Rooms use a fraction of the traffic. A hundred people works now.
- The host leaving is no longer a spinning name picker.
- Click the BPM number and type.
- Track colours. Click the dot by the name.
- The 808 no longer clicks at the start of a note.
- Settings opens again.

## 1.2.1
- "Restart in 1 minute" no longer traps you. It counts down in the corner so you can keep working.
- Section markers work again.
- Right-clicking the ruler opens a menu instead of dragging the repeat region.
- You can clear the repeat region.
- The piano roll opens where the instrument lives, so a bass starts low.
- 808 Bass stops turning into a whistle up high.
- The shortcut list is up to date.

## 1.2.0
- Multiplayer: the host checks every change coming in, so a modified app can't ignore the rules. Removed means removed.
- The signed-in name updates properly.
- Clearer sign-in messages, with a button straight to registering.
- Usernames are checked against a profanity list.
